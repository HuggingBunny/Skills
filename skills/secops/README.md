# SecOps & Detection Engineering Skills

Automations, threat analysis routines, and security workflow skills designed for AI agents operating in enterprise SecOps, SOC, and DevSecOps environments.

## Coming Soon / Roadmap

- **`rule-converter`**: Convert detection rules across Sigma, Suricata, and native SIEM formats.
